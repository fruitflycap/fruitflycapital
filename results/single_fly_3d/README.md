# Single-fly 3-D experiment outputs

Generated by `experiments/autonomous_flight_experiments.py`. The run is deterministic and uses seed `20260909`. The physics mirrors `frontend/src/fly/FlyBody.ts`.

The current server has no live Brian2 rate provider. `malecns_connected` therefore means the exact sensory encoder and `FlightMotorDecoder` are connected, but the decoder receives an empty rate window. This produces zero neural thrust/yaw/pitch/roll and is reported as a limitation, not as autonomous success. `motor_output_disabled` zeros every actuator channel. No parameter tuning or target-following rule is used.
The complete JSON Lines telemetry is compressed as `telemetry.jsonl.gz`; the same flat telemetry is in `telemetry.parquet`.
